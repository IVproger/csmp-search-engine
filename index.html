Motivation and Core Problem

In tandem mass spectrometry, many spectra remain unannotated because classic library matching works well only for known compounds. In real lab practice, chemists often face novel molecules, heterogeneous instrument settings, and inconsistent metadata, which turns annotation into a slow and expert-heavy process.

This thesis asks a practical question: can we move from isolated ML experiments to an end-to-end system that actually helps identify molecules from MS/MS spectra at scale?

Research Questions and Goals

RQ1: Data Foundation

How to transform noisy, heterogeneous public MS/MS resources into a reliable, leakage-aware benchmark for training and evaluation?

RQ2: Model Benchmarking

How well do modern dual-encoder methods (JESTR, CSU-MS2) solve spectrum-molecule matching under one unified protocol?

RQ3: Deployment

Can the strongest model be deployed in a robust retrieval system with practical speed, scalability, and failure-safe behavior?

Component Rollup (Architecture in One View)

The deployed system is a modular pipeline: Web UI → FastAPI orchestration → Spectrum preprocessing → Triton inference (CSU-MS2 encoder) → Mass-filtered candidate generation + embedding ranking → Result table with molecule details.

Takeaway for the Committee

This thesis delivers not only model experiments, but a reproducible end-to-end system. The key contribution is the integration of large-scale data engineering, unified model benchmarking, and deployable software architecture into one practical retrieval workflow.

The system is not yet a fully autonomous molecular identifier, but it already works as a reliable hypothesis-generation tool that narrows candidate space and supports expert decision-making in realistic analytical settings.
